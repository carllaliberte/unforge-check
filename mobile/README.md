# Mobile v0 — digest only

Open `index.html` locally. Pick file + `.unforge.json`.
VERT = sha256 match. ROUGE = refuse.

After VERT/ROUGE, Share uses the Web Share API when the browser has it
(`navigator.share`, files if `canShare` allows). Otherwise the page shows
the result to copy, plus the page URL when it is http(s). Local `file://`
has no web link — the result text is what you copy. Not a seal.

Not the App Store. Not issuing. Not QUANTUM.
Ed25519 / UFHY1 stay in `check.py`.
