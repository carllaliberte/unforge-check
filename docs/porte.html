UNFORGE · Check

Dépose un fichier. Vois s’il correspond encore à sa carte. VERT / AMBRE / ROUGE.

python3 check.py examples/bienvenue.txt --human

VERT = le fichier correspond encore à sa carte. VERT means the file matches the card. Pas un sceau. Pas une quittance.

AMBRE = carte v1 (l’objet n’était pas dans le sceau). ROUGE = ça ne correspond plus.

Imprimer la carte A5 : unforge-press — python3 press.py examples/bienvenue.txt.unforge.json
